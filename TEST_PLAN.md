## Critical Regression Tests (run on every change)

1. **Settings merge preserves unrelated keys** — Given `settings.json` with `{ "env": { "ANTHROPIC_MODEL": "opus" }, "version": 1 }`, merge profile with only `base_url` set. Result must preserve `version` and `ANTHROPIC_MODEL`.
2. **Delete active profile switches to first remaining** — If profile[0] is active and deleted, active becomes profile[1] (or empty state if none).
3. **Locale switch takes effect immediately** — Call `set_locale('zh')`, verify `invoke('get_config')` returns `'zh'`.
